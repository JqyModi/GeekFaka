# AI 图片提示词包 v1

适用场景：电商主图、社媒封面、活动海报、课程封面、产品概念图。

使用方式：

1. 复制一个场景模板。
2. 替换方括号里的主体、风格、用途和尺寸。
3. 每个场景至少生成 4 张，保留点击率或转化率最高的版本。
4. 二次生成时只改一个变量，避免无法判断哪个因素有效。

## 电商主图

```text
为 [产品名称] 生成一张高转化电商主图。画面主体居中，占画面 65%，背景干净，有轻微纵深。突出 [核心卖点]，避免夸张文字和复杂装饰。风格：高级、可信、适合移动端浏览。比例 1:1。
```

```text
把 [产品名称] 放在真实使用场景中，展示用户获得 [结果/好处] 的瞬间。背景包含少量生活化道具，但不能抢主体。光线柔和，画面有商业广告质感。比例 4:5。
```

```text
为 [产品名称] 生成一张对比型主图，左侧表达使用前的痛点，右侧表达使用后的改善。画面不使用大段文字，只用视觉差异传达价值。比例 1:1。
```

## 社媒封面

```text
为一篇主题为 [内容主题] 的社媒帖子生成封面图。画面需要让人一眼理解主题，中心视觉是 [核心元素]，背景有轻微层次。风格：清晰、现代、适合小屏幕点击。比例 4:5。
```

```text
生成一张适合小红书/Instagram 的教程封面，主题是 [教程主题]。画面包含步骤感和结果感，避免廉价模板感。色彩明亮但不过饱和。比例 3:4。
```

```text
为 [目标人群] 设计一张痛点型封面，视觉表达 [痛点]，同时暗示 [解决方案]。画面要有停顿感，适合信息流里吸引点击。比例 4:5。
```

## 活动海报

```text
为 [活动名称] 生成一张促销海报主视觉。核心情绪是 [情绪关键词]，主体是 [产品/人物/场景]。留出上方 20% 和下方 15% 的文字安全区。比例 9:16。
```

```text
生成一张 [节日/节点] 活动 KV，适合电商首页或社媒投放。画面需要体现 [优惠/新品/限时]，但不要出现具体价格文字。风格：商业、干净、有购买欲。比例 16:9。
```

```text
为 [品牌/店铺] 生成一张新品发布视觉。主体是 [新品名称]，关键词是 [质感关键词]。背景使用真实材质和柔和光影，避免虚假过度渲染。比例 4:5。
```

## 内容生产

```text
把 [文章标题] 转换成一张可点击封面图。画面需要表现问题、冲突或结果，不要直接堆文字。适合公众号、知乎、博客缩略图。比例 16:9。
```

```text
为 [视频主题] 生成一张短视频封面。画面应包含强烈的前后反差，主体清晰，背景简洁，适合手机端快速识别。比例 9:16。
```

```text
为 [课程/资料名称] 生成一张数字产品封面。视觉要体现专业、可执行、信息密度高但不杂乱。适合在线商店商品图。比例 1:1。
```

## 调参建议

- 如果画面太花：增加“背景简洁，最多三个视觉元素”。
- 如果主体不清楚：增加“主体占画面 65%，边缘清晰”。
- 如果商业感不足：增加“真实广告摄影、柔和布光、可用于电商投放”。
- 如果文字乱码：不要让模型直接生成文字，后期用设计工具加字。
