## 当前核心问题

1. 内容分发量太少，样本不足。
2. 已发内容转化意图偏弱：小红书浏览低，Pinterest 只有单 Pin，知乎问题流量小。
3. 商品页缺少“买前可见样例”和“买完得到什么”的强信任证明。
4. 站内轻量埋点已上线，后续以后台增长页为主，Nginx 日志只做交叉验证。
5. 微信公众号有阅读但无互动/站内成交，需要把 CTA、站内样例和追踪链路补强后再加量。

- 使用已上线的站内访问归因事件：记录 `page_view / product_view / checkout_open / checkout_submit / order_created`。

### P0：优化当前两个商品页

- 给每个商品加 `免费样例` 区块：展示 3-5 条可复制模板。

- 增加组合包或优惠：`提示词包 + 内容工作流`，目标提高客单价到 `¥59-¥79`。
