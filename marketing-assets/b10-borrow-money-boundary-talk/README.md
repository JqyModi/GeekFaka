# B10 借钱拒绝话术

定位：高收藏、强共鸣、弱转化内容资产。

目标用户：不擅长拒绝、怕伤关系、容易被亲戚朋友借钱请求消耗的普通人。

核心欲望：

- 不想借钱，但不想撕破脸。
- 想说得体面一点，不想显得冷血。
- 想保住边界，不想被对方继续拉扯。

发布策略：

- 微信公众号：用生活关系痛点承接，正文短，首图做“9 句话清单”，评论/关注关键词 `借钱`。
- 小红书：封面强钩子 + 9 句话清单图，正文少讲道理，重点引导收藏。
- 不放裸商品链接，先观察收藏、评论、关注。

- `wechat-article.md`：公众号正文。
